# MyRooms

Gaming center management app: rent PC desks and PlayStation rooms by the hour, manage live sessions and reservations on a calendar, record payments (Cash / Visa / Instapay) and track income across branches.

Runs on **Windows**, **Android / iOS** and the **Web** from one Expo (React Native + TypeScript) codebase, with a Supabase cloud backend and offline support.

**Status:** planning. See the full plan and implementation phases in [docs/PLAN.md](docs/PLAN.md).
